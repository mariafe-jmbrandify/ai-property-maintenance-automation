# Prompt: Weekly Management Report (Scenario 11)

KPI numbers are computed in code / Google Sheets formulas. The AI only writes the narrative.

```text
Write a weekly maintenance operations report for the owner and operations manager.

Use ONLY the metrics provided. Do not calculate new numbers.
Structure:
1. Highlights (3 bullets)
2. Issues detected (each with the metric that shows it)
3. Recommendations (one per issue, specific and actionable)
4. Watch list for next week

Keep it under 250 words. Plain language, no jargon.

METRICS (this week vs last week):
{{metrics_json}}
```
